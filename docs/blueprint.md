# **App Name**: Compras DMR

## Core Features:

- User Access Control: Secure user authentication with role-based access control for employees (requesters) and purchase managers.
- Request Submission: Intuitive form for employees to submit purchase requests, including auto-filled user info, priority levels, detailed descriptions, and attachments.
- Request Management: Centralized dashboard for purchase managers to view, filter, and manage all requests with status updates, comments, and activity history.
- Request Tracking: Dashboard for employees to track their requests' statuses, closure dates, and final amounts, promoting transparency.
- Notifications: Automated notifications for status changes and new requests, ensuring timely communication.
- AI-Powered Request Review: Use an AI tool to parse purchase requests and make suggested improvements for clarity, completeness, and policy compliance.

## Style Guidelines:

- Primary color: Deep blue (#3F51B5) to convey trust and reliability.
- Background color: Light gray (#F5F5F5) for a clean and professional look.
- Accent color: Soft orange (#FFAB40) to highlight key actions and information.
- Body and headline font: 'Inter' sans-serif for a modern, machined, objective, neutral look.
- Simple, consistent icons for categories, status indicators, and actions.
- Clean, well-organized layout with clear visual hierarchy and easy navigation.
- Subtle transitions and animations for status updates and form submissions.
